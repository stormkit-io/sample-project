How this page was rendered

This is a single static product.html from the build. The rule below in redirects.json tells Stormkit to fetch the product from dummyjson.com on every request and fill the {{data.*}} placeholders before the HTML leaves the server — so the title, description and Open Graph tags are right for crawlers and link previews, with no SSR. 

{
  "from": "/products/*",
  "to": "/product.html",
  "data": {
    "url": "https://dummyjson.com/products/$1",
    "passthroughStatus": true
  }
}
